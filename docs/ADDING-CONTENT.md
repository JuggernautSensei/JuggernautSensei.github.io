# 같은 스타일로 콘텐츠 추가하기

## 첫 화면 배경

공개할 이미지 파일을 `src/assets/media/`에 넣고 `src/_data/hero.json`의 `slides`에 항목을 추가합니다.

```json
{
  "src": "/assets/media/new-project.png",
  "label": "프로젝트 이름 · 설명",
  "href": "/projects/new-project/",
  "position": "60% center"
}
```

추가한 순서대로 전환합니다. 간격은 `intervalMs`이며 현재 6500ms, 교차 시간은 CSS에서 1.8초입니다.
서로 겹쳐 전환하므로 배경이 검게 비는 구간을 만들지 않습니다. 정지·직접 선택·모션 줄이기를 유지합니다.
배경에 맞춰 문구가 바뀌더라도 자기소개와 주 메뉴의 위치는 유지합니다.

## 소개와 사진

`src/_data/profile.json`에서 소개글·사진 경로·연락처·학력·활동·수상을 편집합니다.
메인의 소개부터 연락처까지 스크롤하면 모두 확인할 수 있습니다. 사진 아래에는 이름만 표시합니다. 개별 프로젝트는 메인 위에 서브 페이지로 열립니다.
원본 Notion과 연결된 소개·사진 필드는 동기화 실행 시 갱신되므로 `docs/NOTION-SYNC.md`의 반영 범위를 확인합니다.

## 프로젝트

`src/projects/`에 Markdown 페이지를 추가하고 `src/_data/projectCatalog.json`에 해당 slug·Notion ID·제목·공개 URL·categories를 등록합니다.
목록은 `pinned: true`인 대표 작업을 먼저 보여주며, 대표 작업과 나머지 항목 각각의 순서는 공개 Notion의 All 보기 순서를 유지합니다. 필터는 전체 → 프로젝트 → 라이브러리 → 게임 → 발표 → 학습 순서입니다.
categories는 배열이므로 Project·Library, Project·Game, Study·Game처럼 중복 분류할 수 있습니다. 각 필터 안에서도 대표 작업을 우선하고 같은 그룹 내 All 보기 순서를 유지합니다.
기존 파일의 공개 승인 필드와 레이아웃 구조를 따릅니다. Notion 목록에 없는 기존 페이지는 파일을 지우거나 덮어쓰지 않고 보존합니다.
대표 작업에는 `pinned: true`를 지정합니다. 별도 대표 프로젝트 섹션 없이 전체 프로젝트 목록의 앞쪽에 표시합니다.
프로젝트 카드는 썸네일 → 제목 → 회색 설명 1~2줄 순서입니다. 기존 공개 이미지의 `cover`·`coverAlt`를 사용하며, 표지가 없는 항목에는 같은 크기의 임시 플레이스홀더를 표시합니다. Notion 연결 항목은 공개 페이지 표지를 우선 사용하고, 표지가 없으면 Markdown의 `cover`·`coverAlt`를 사용할 수 있습니다. 화면 표시 이름을 저장소 이름과 다르게 쓰려면 `displayTitle`을 추가합니다.
`src/_data/projectThumbnails.json`에 slug별 이미지 경로를 지정하면 목록의 썸네일만 교체할 수 있습니다. `null`은 플레이스홀더를 강제합니다. 이 설정은 Notion 동기화로 덮어쓰지 않으며, 별도 지정이 없으면 기존 표지를 사용합니다. JugGfx와 JugNet의 단색 표지는 플레이스홀더로 대체합니다.
근거 없는 성능·기간·기여도나 새 이미지를 만들어 채우지 않습니다.

## 메인 구성

히어로 → 소개 → 학력·활동·수상 → 기술 문서와 학습 → 전체 프로젝트 → 연락처 순서입니다. 소개 아래 기술 키워드 줄은 표시하지 않습니다.
기술 자료는 Deferred Rendering 발표·다층 퍼셉트론 조사 보고서·노션 기술 블로그 세 카드를 데스크톱에서 한 줄로 배치합니다.
히어로 제목은 `직접 [구현하며 → 검증하며 → 디버깅하며 → 소통하며 함께] 만듭니다.`를 가로 한 줄로 표시합니다. 함께는 마지막 문구에만 포함됩니다. 직함 → 가로 제목 → 설명 순서로 쌓고, 모든 화면 크기에서 같은 왼쪽 시작선에 맞춥니다. 대문의 프로젝트·소개 이동 버튼과 스크롤 안내는 표시하지 않습니다.
연락처(이메일·디스코드)와 소셜(깃허브·노션 기술 블로그)을 별도 그룹으로 구분합니다. 중복되는 이름·자기소개·국가 표시는 이 영역에 넣지 않고 짧은 연락 안내만 둡니다.
왼쪽 메뉴 소개는 '직접 구현하고 검증하며, 함께 만드는 프로그래머' 고정 문구입니다. 메뉴 아래는 연락처(이메일·디스코드)와 소셜(GitHub·블로그)을 같은 형식의 두 그룹으로 구분하고, 우측 상단의 이름표는 표시하지 않습니다.
푸터는 작은 저작권 표시와 맨 위로·제작 정보 링크만 둡니다. 템플릿의 제작자 고지와 MIT 전문은 제작 정보와 licenses에 보존합니다.

## 서브 페이지

프로젝트 카드를 누르면 `<dialog>` 안에 해당 로컬 상세 페이지를 `?embed=1`로 엽니다. 배경 목록과 스크롤을 보존합니다.
닫기·Esc·바깥 클릭·뒤로 가기로 목록에 돌아오며, 새 페이지로 보기와 프로젝트 직접 URL도 지원합니다.
모달 주소의 `project=slug`는 공유하거나 새로고침할 수 있습니다. 내용 안에서 Esc를 눌러도 닫혀야 하며, 외부 원문은 새 탭으로 엽니다.
본문 전체가 아직 이전되지 않은 항목은 관련 자료의 공개 Notion 원문 링크를 보존합니다.

## 재사용 스킬

설치된 `$jiwoo-portfolio`에 프로젝트 추가, 공개 Notion 변경 반영, 배경 이미지 추가를 요청할 수 있습니다.
승인한 다크 디자인·한글 문구·한 페이지 소개와 공개 범위 원칙을 보존합니다.
예: `$jiwoo-portfolio 새 프로젝트를 추가하고 첫 화면 배경에도 넣어줘.`

## Notion에서 관리하기

공개 All 데이터베이스에 항목을 추가하면 본문·표지·다중 분류·순서가 자동 반영됩니다. 대표 항목은 Pinned 태그와 Library/Game 분류를 사용합니다. 공개 원본에 본문이 없으면 수동 Markdown을 유지합니다. 자세한 범위는 [Notion 자동 갱신](NOTION-SYNC.md)을 따릅니다.
첫 화면 배경은 5초 간격, 1.4초 교차 페이드로 자동 전환하며 하단 조작 버튼과 프로젝트 링크는 두지 않습니다. 운영체제의 모션 줄이기는 존중합니다.

사이트 제목은 `프로그래머 안지우`, 첫 배경은 레이트레이싱으로 둡니다. 자신을 소개하는 직함은 프로그래머이며 기술 분야와 프로젝트의 C++ 표기는 유지합니다. 노션에서 가져온 소개 문구의 C++ 개발자라는 직함은 화면에서 프로그래머로 표시합니다.
